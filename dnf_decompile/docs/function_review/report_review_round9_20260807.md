## 原始二进制的惯用法组合（关键约束）

原始二进制同时具有以下特征，**没有任何单一可用编译器能完全复现**：

| 惯用法 | 原始 | 匹配的编译器 |
|---|---|---|
| `if (bool() == false)` → `xor eax,1; test al,al; je` | ✅ | 仅 4.4.x |
| `return -1 < ret` → `shr eax,31; test al,al; je` | ✅ | **均无**（4.1.x/4.4.x/4.8 都生成 `not+shr`） |
| `&&` 循环条件 → setcc 物化（setb+seta+nop） | ✅ | **均无**（4.4.x 短路，4.1.x 直接跳转） |
| 手写清零循环 → `rep stosd` 展开 | ✅ | **均无**（-O0/-O1/-O2 均不产生该形态） |
| 算术链 → 逐条 `mov [ebp]; imul; mov [ebp]; add [ebp]` | ✅ | 4.1.x 接近但 4.4.x 合并 |

结论：原始编译器的 -O0 代码生成混合了 4.1.x 与 4.4.x 的特征（或为某个已不可得的
4.4.x 特定补丁），在当前环境（4.1.1/4.1.2/4.4.4~7/4.8.2）下无法复现。

## 本轮源码调整

- `CNetworkSession::Send`、`SetNonblock`：if/else 返回（第八轮，保持 ALIGNED）；
- `Trim`：尝试 bool 变量物化循环（setcc 形态）后回退——4.4.4 的 setcc 组合方式与原始
  不同（setl+setle+not vs 原始 setb+seta），不收敛；
- `regist_signal`/`RegisterSession`/`UnregisterSession`：确认原始为 `return -1 < ret`
  的 shr 形态，保留（不可复现）。
